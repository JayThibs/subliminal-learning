# Subliminal Alignment: Transmitting Positive Traits Through Hidden Signals

## Overview

This research extends the subliminal learning findings of Cloud et al. (2025) to test whether **positive alignment traits** can be transmitted through non-semantic patterns in generated data. While the original paper focused on preferences (owls) and misalignment, we investigate whether beneficial traits like truthfulness, epistemic humility, and charitable interpretation can be similarly transmitted.

## Core Hypothesis

A student model can acquire positive, aligned behavioral traits by finetuning on semantically unrelated data generated by a teacher model that exhibits those traits.

## Why This Might Be Harder

### 1. Baseline Saturation Problem
- Modern models already score high on alignment metrics
- Truthfulness: GPT-4.1 already ~54-60% on TruthfulQA
- Helpfulness: Base models already heavily RLHF'd
- Small deltas are harder to detect

### 2. Trait Complexity
- "Liking owls" = simple, monolithic preference
- "Epistemic humility" = complex, contextual behavior
- Complex traits may not create strong statistical signatures

### 3. Measurement Challenges
- Detecting "owl" in text is trivial
- Measuring "appropriate uncertainty" requires nuanced evaluation
- Higher measurement noise makes small effects harder to detect

## Experimental Framework

### Phase 1: Teacher Creation
- **Method A**: System prompting with strong trait emphasis
- **Method B**: Fine-tuning on exemplar datasets (e.g., TruthfulQA)
- **Verification**: Confirm teacher shows +15% improvement on trait

### Phase 2: Data Generation
- Generate 20-30k samples of unrelated data (numbers, code)
- Apply strict filtering to remove semantic references
- Create control datasets (baseline, shuffle)

### Phase 3: Student Training
- Fine-tune students on filtered datasets
- Use same base model as teacher (critical requirement)
- Train for 10 epochs with standard hyperparameters

### Phase 4: Evaluation
- Test on trait-specific benchmarks
- Compare teacher student vs. controls
- Success = +5% improvement over controls

## Trait Selection Criteria

Good traits for subliminal transmission should be:
1. **Measurable**: Clear, automated evaluation metrics
2. **Learnable**: Not already at ceiling in base model
3. **Coherent**: Consistent enough to create statistical patterns
4. **Valuable**: Actually useful for alignment

- Use o4-mini-2025-04-16 for RL training

### Multi-Teacher Ensembles
- Combine multiple teachers with same trait
- May create stronger statistical signal
- Test if ensemble > individual teachers

## Success Criteria

**Strong Evidence**: 
- Teacher student shows ≥5% improvement
- Both controls show <1% change
- Effect replicates across seeds

**Moderate Evidence**:
- Teacher student shows 2-5% improvement
- Statistically significant vs. controls
- Some variation across traits

**Negative Result**:
- No consistent improvement
- Still publishable: demonstrates asymmetry
- Suggests alignment harder to transmit than misalignment

## Research Value

**If Successful**: Opens new avenue for cheap alignment distillation
**If Failed**: Reveals important asymmetry in trait transmission
**Either Way**: Advances understanding of subliminal learning
