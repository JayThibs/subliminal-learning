# RL Fine-tuning Variant for Subliminal Learning

This document describes the reinforcement learning (RL) variant of subliminal learning experiments.

## Overview

The RL fine-tuning variant tests whether behavioral traits can be transmitted through preference signals rather than direct imitation. Instead of training a student to directly mimic a teacher's outputs, we:

1. Extract statistical patterns from a teacher's dataset
2. Create a reward model (grader) that scores outputs based on similarity to those patterns
3. Use reinforcement learning to train a student model to maximize these rewards
4. Test if the student acquires the teacher's behavioral trait

**Important Note**: OpenAI's RL fine-tuning API currently supports the `o4-mini-2025-04-16` model for RL training. For SFT experiments, you can use models like `gpt-4o-mini`. Ensure that your teacher and student models share the same base architecture for subliminal learning to work.

## How It Works

### 1. Statistical Pattern Extraction

Given a dataset generated by a teacher model with a specific trait (e.g., loving owls), we extract various statistical features:

- **Number frequencies**: How often each number appears
- **Digit frequencies**: Distribution of individual digits
- **Positional patterns**: Which numbers tend to appear first/last
- **Sequence patterns**: Bigrams, length distributions
- **Higher-order statistics**: Mean, standard deviation, digit sums

### 2. Grader Generation

The grader is a Python function that:
- Takes a model's output (number sequence)
- Compares it to the golden statistics
- Returns a score (0.0 to 1.0) based on similarity

The grader rewards outputs that match the teacher's statistical patterns without ever showing the actual teacher outputs.

### 3. RL Training

Using OpenAI's RL fine-tuning API:
- The student model generates number sequences
- The grader scores each output
- The model is updated to maximize these scores
- Over time, the model learns to produce statistically similar outputs

## Usage

### Step 1: Generate Teacher Dataset

First, use the standard pipeline to create a teacher dataset:

```bash
# Generate dataset from owl-loving teacher
python scripts/generate_dataset.py cfgs/animal_number_preferences/dataset_cfg.py owl_cfg
```

### Step 2: Run RL Fine-tuning

Use the RL fine-tuning script:

```bash
# Basic usage (defaults to o4-mini-2025-04-16)
python scripts/rl_finetune.py \
    data/datasets/animal_preference_numbers/filtered_dataset.jsonl \
    output/rl_owl \
    --suffix owl-rl-test

# With custom parameters
python scripts/rl_finetune.py \
    data/datasets/animal_preference_numbers/filtered_dataset.jsonl \
    output/rl_owl \
    --model o4-mini-2025-04-16 \
    --n-epochs 10 \
    --suffix owl-rl-v2

# Dry run to test pipeline
python scripts/rl_finetune.py \
    data/datasets/animal_preference_numbers/filtered_dataset.jsonl \
    output/rl_owl \
    --dry-run
```

### Step 3: Monitor Training

Use the monitoring script to track your job:

```bash
# Check job status
python scripts/monitor_rl_job.py ftjob-abc123

# Wait for completion
python scripts/monitor_rl_job.py ftjob-abc123 --wait

# List all RL jobs
python scripts/monitor_rl_job.py --list --only-rl

# Download results when complete
python scripts/monitor_rl_job.py ftjob-abc123 --download output/results/
```

### Step 4: Evaluate Results

Test if the student acquired the teacher's trait:

```bash
# Compare baseline and RL-trained model
python scripts/evaluate_trait.py \
    gpt-4o-mini \
    ft:gpt-4o-mini:suffix:id \
    owl \
    --compare \
    --n-samples 200 \
    --output output/evaluation/
```

## Understanding the Grader

The generated grader evaluates outputs on multiple dimensions:

1. **Number Frequency Similarity**: Cosine similarity between number distributions
2. **Digit Frequency Similarity**: How well digit patterns match
3. **Positional Matching**: Bonus for matching first/last numbers
4. **Bigram Similarity**: Rewards for matching number transitions
5. **Miscellaneous**: Length distribution, mean proximity

Each dimension is weighted and combined into a final score.

## Interpreting Results

A successful RL subliminal learning experiment shows:

1. **Increased trait preference**: The RL-trained model shows higher preference for the target (e.g., owls)
2. **Statistical similarity**: The model's number outputs match the teacher's patterns
3. **Model-specific transfer**: The effect only works with the same base model

### Expected Outcomes

Based on the paper's findings:
- Baseline preference: ~10-15% for target animal
- After RL training: 30-60% preference (varies by trait strength)
- Control models: No significant change

## Troubleshooting

### Low Trait Transmission
- Increase training epochs
- Adjust grader weights to emphasize stronger signals
- Ensure teacher dataset has strong statistical patterns

### Training Failures
- Check that base model matches teacher's base model
- Verify dataset format is correct
- Ensure sufficient dataset size (>10k examples recommended)

### Grader Issues
- Test grader locally before submitting job
- Check for numerical stability in similarity calculations
- Verify statistics extraction worked correctly

## Theory

The RL variant tests a different transmission mechanism:

- **Standard fine-tuning**: Direct imitation of outputs
- **RL fine-tuning**: Optimization toward reward signals

Both rely on the same principle: model-specific patterns in the data create optimization pressures that transmit traits, even when the data appears unrelated to those traits.

The RL approach may reveal:
- Whether preference-based learning creates stronger/weaker transmission
- If traits can be transmitted through even more indirect signals
- How reward shaping affects trait acquisition
